# Contributing

Use Node.js 20 or later. Run `npm test` and `npm run demo` before proposing a change. Keep tests offline, examples fictional and state in a caller-owned temporary directory. Add failure-path coverage when changing evidence, ownership, timeouts or persistence.

Describe the concrete behavior, exact checks and limitations. Never include credentials, customer data, private logs or provider prompt dumps. Claims about quality or savings need measured comparisons.
